Companion to `metaphysicist-weapons-endgame.json`.
Generated by `tools/mp-weapon-extractor/gen-weapons-endgame.ps1` from
`tools/mp-weapon-extractor/Program.cs`, which reads `items.ocp` directly.

unknown. Per the playbook §0: nothing here is invented. Where something could not be
verified it says "unknown" rather than approximating.

## 2. What changed from the previous version, and why

The previous file had 770 models and three problems. All three are fixed.

### 2a. "Bow Skill NCU (6/6)" was tagged as a Xan weapon — it is not a weapon at all

**Verified from the data.** The Legacy of the Xan `"<skill> Skill NCU (n/6)"` chips
really do carry a `ToWield` action with a weapon-skill requirement — e.g.
`1-Hand Blunt Skill NCU (1/6)` (id 278310) requires `1hBlunt 5` and
`ComputerLiteracy 7` — which is why the old "has a weapon-skill ToWield requirement"
test caught them. They also carry the LoX expansion bit, which is why the old
classifier then called them Xan weapons.

They are not weapons. Their `Slot` stat (298) is `0x7E00` = Deck slots 1–6, they have
an **empty attack table** and **zero damage**. Real weapons sit in the RightHand
(`EquipSlot` 0x06) or LeftHand (0x08) bit.

Fix: the extractor now reads the item's `Attack` and `Stats` dictionaries, and the
generator requires a **hand slot**. That removed **480 NCU chip models** plus 81 other
Utils/HUD items — 561 non-weapons in total. Only 3 hand-held items in the whole pool
have no damage, so the hand-slot test is clean.

**Answer to the question asked:** no, those entries are not weapons; they have a real
`ToWield` weapon-skill requirement but no hand slot, no attack table and no damage.
They were **excluded**, not reclassified.

### 2b. Line classification no longer uses the expansion bit

The expansion bit (stat 389) means *"you need this expansion to wield this"*, not
*"this is that expansion's weapon line"*. Using it as a line classifier is what
produced the bad Xan labels. Lines are now matched by **item name** against verified
name sets, and the expansion bit is reported in its own column.

Sanity check on the result: the 18 models now classified `Xan` are exactly the 18
LoX-gated hand-held MP-usable models in the pack, and they match the independently
researched Xan weapon list item for item.

### 2c. Tightened what counts as endgame — the rule used

Applied to each model **at its top QL** (requirements and damage scale with QL):

| Tier | Rule | Authoritative? |
|---|---|---|
| `TL7` | `ToWield` carries `TitleLevel >= 7` → level 205+ | **Yes** — read from the item |
| `TL6` | `ToWield` carries `TitleLevel = 6` → level 190+ | **Yes** — read from the item |
| `expansion` | no TitleLevel gate, top QL ≥ 200, max damage ≥ 300, and an `Expansion(389)` gate | expansion gate yes; QL/damage floor is a **judgement call** |
| `high-rk` | same QL/damage floor, no expansion gate | **judgement call** |

The big find here is **TitleLevel (stat 37)**, which had not been read before. It is
the one signal in the client data that says "this is endgame content" outright, and it
is exact: 31 models carry it (TL6 = level 190+, TL7 = level 205+).

QL alone is a weak signal — ordinary shop weapons also span QL 1–200 — so the lower
two tiers add a `max damage >= 300` floor. **That floor is a threshold chosen for this
file, not a fact**, and it is recorded as such in `_unverified`. Tune it in the script
if you disagree.

Net effect: 770 → 534 models, with the 480 non-weapons gone and the remaining
"generic" bucket reduced from 474 to 438 (and those 438 are now genuinely QL200+,
300+ damage weapons, not QL200 shop filler).

### 2d. Deliberate exclusions (10 models)

Listed individually in `_unverified.excludedModels`:

- **NPC/monster-only templates** (5): `Uriel Blade - Monster`, `Uriel Short Sword -
  Monster`, `Uriel Staff - Monster`, `Uriel Sword Staff - Monster`,
  `Viper Staff - monster only - LH`.
- **Player-unreachable templates** (4): `Viper Staff` (2178 max damage at a skill
  requirement of 218), `Low/`/`High Novictum Katana of Innocence` (up to **13000** max
  damage at a requirement of **1**). These are GM/test items.
- **Unverifiable name** (1): one model had no row in `itemnames.sql`. The playbook
  requires every name to be verified there, so it is excluded rather than shipped as
  "(no name)".

## 3. The Xan weapon line — what is verified

This was the headline request. The answer is in `xanWalkthrough` in the JSON. The key
correction: **Xan weapons are not a drop.** Every one starts as a Shadowlands Beast
weapon and is upgraded.

```
The Beast (Pandemonium, Shadowlands)        Legacy of the Xan team instances
   drops Lord of <Sin>  QL300                  drop Xan Weapon Upgrade Device
   drops Lady of <Sin>  QL299                  (QL300, NODROP, consumed)
              \                                        /
               \______________  combine  _____________/
                        (no tradeskill skill)
                                  |
                          <Sin> of the Xan          TL6, level 190+
                                  |
                      + one shop component QL150+
                                  |
                        Modified Xan Weapon         (only 5 sins have one)
```

**Where the starting piece drops** — The Beast, the final boss of the **Pandemonium**
playfield (Shadowlands). 9-hour respawn; an instanced version exists via an altar just
inside the zone. Over 104 documented kills it dropped 2–4 weapons, 4 armour pieces,
both hilts, 1–2 profession stars and one Shadowbreed per kill. Sunrise Hilt 18.27%,
Sunset Hilt 4.81%. No per-weapon drop rate is published.

**Where the upgrade device drops** — all three LoX team instances, entered by floor
portals in the Central Hub: The Alien Threat / "Mitaar Hero" (portal 350 x 410, boss
Technomaster Sinuh), LoX: Ground Chief Vortexx (portal 523 x 307), The Xan 12-man
(portal 419 x 324, final boss Deranged Xan). Since 18.3 none need the old prerequisite
quests. No drop rate published.

**Melee Energy is the exception** — there is no "Lord of" weapon for it. Sword of Dawn
(Notum Seed + Sunrise Hilt, Clan) and Sword of Dusk (Novictum Seed + Sunset Hilt,
Omni) are built in Pandemonium at **500 Weapon Smithing** — the only real skill
requirement anywhere in the line — and feed Dawn/Dusk of the Xan.

**Cross-check against the client data:** every step above is corroborated locally. The
sin → weapon-skill mapping in the walkthrough is read from each item's own `ToWield`
(Abandonment = 1hBlunt, Hatred = 1hEdged, Pride = 2hEdged, Gluttony = 2hBlunt,
Chaos = Bow, Lust = Pistol, …), and the description string on `Peh'Wer Pistol`
(id 281505) literally reads that the Lust of the Xan has been tweaked to higher
performance — confirming the Modified tier.

### The "Corrupted Lord of X" tier — resolved

The pack contains `Corrupted Lord of <Sin>` (ids 302933–302949), QL300, LoX-gated,
**TitleLevel 7**. These are **not** an upgrade above `<Sin> of the Xan`: they are a
**parallel drop line** from the **Pyramid of Home** ("Dark Pyramid Below") 6-man
level 201–220 dungeon, added in patch 18.8.6. Patch 18.8.8 renamed a duplicate
"Chaos of the Xan" entry into the Corrupted Lord of Chaos — which is exactly why the
two sets share flavour text in the client data while differing in damage and gate.
Entrance: the large door behind Number Nine in the Temple of Home, Broken Shores.

## 4. Provenance — verified locally vs from the web

### Verified from LOCAL client data (authoritative, no web involved)

- Every **item id and name** — `items.ocp`, names joined from `itemnames.sql`.
- Every **wield requirement** and **special-attack requirement** — the item's `ToWield`
  criteria.
- **Expansion gate** — `Expansion(389) BitAnd`, bit 1 = Shadowlands, 3 = AlienInvasion,
  5 = LostEden, 7 = LegacyOfTheXan.
- **Title level gate** — `TitleLevel(37)`.
- **Profession lock** — `Profession(60) EqualTo`.
- **Damage, attack delay, recharge delay, critical bonus, attack range, damage types,
  equip slot** — the item's `Stats` dictionary. Damage-type values (90–97, 168)
  verified against OmniCell's `DamageType.cs`, not assumed.
- **Skill cost factors** used in the ranking — `profiles/reference/skillcaps.json`.

### From the WEB (every claim cited in `_sources` with its URL)

Only `ao-universe.com` and `wiki.aodb.us` were used, plus two `forums.funcom.com`
pages where explicitly marked as player reports. `auno.org`, `aoitems.com` and
`anarchyonline.fandom.com` are blocked to automation and **nothing was taken from
them**.

Covered lines: Xan upgrade chain, Beast/Pandemonium, Sword of Dawn/Dusk, Modified Xan,
Pyramid of Home, Ofab, Kyr'Ozch typing, Sector 7, Sector 42 / High Lord of Angst,
Perennium.

### Still UNKNOWN — stated, not approximated

- **441 of 534 models (83%) have `acquisition.how = "unknown"`.** These are the
  high-QL generic and expansion weapons with no documented line. Their `source` text
  says so explicitly. This is the honest ceiling: the per-item drop databases that
  would cover them are exactly the ones blocked to automation, and `items.ocp` carries
  no drop or vendor table (I checked — the `Relations` list is self-referential and
  the descriptions are flavour text only).
- **No drop rate** is published for the Xan Weapon Upgrade Device, individual
  Lord/Lady weapons, Solid Clumps of Kyr'Ozch Bio-Material, Sector 7 Special Editions,
  or anything in Pyramid of Home. The Beast hilts/stars are the only rated drops found.
- **Untyped Kyr'Ozch weapons** — no per-mob or per-playfield table exists on the
  allowed sources; only "the city raid boss and the boss on the alien ship".
- **Ofab Victory Point prices** — no list published. The single figure found
  (1100 VP for a QL75 Ofab Pistol) is a player forum report and is labelled as such.
- **Ofab Type 812 coverage** — ao-universe says Bow, wiki.aodb.us says Crossbow.
  Unresolved; both recorded.
- **Perennium rebuild-kit quest name** — sources disagree ("Yutto's Spirit quest" vs
  "Joining the hunt"). Unresolved.
- **`Mirror of the Xan` / `Shattered Mirror of the Xan`** (ids 273645–273680, 302810)
  — present in the client data, but searches of both allowed sources return nothing.
  Role unknown. Not recorded as a chain component. (They are not weapons — no hand
  slot.)
- **Kuma Tonfa** — ao-universe lists it from Lord/Lady of Wisdom, wiki.aodb.us does
  not. Unresolved; Martial Arts either way, so outside MP's skills.
- A claim that Corrupted weapons can be fed to a Xan Weapon Upgrade Device circulates
  online but traces only to a source outside the allowed list, and the 18.8.8 rename
  note argues against it. **Not recorded as fact.**

## 5. The "best for MP" picks — how to read them

Three picks per weapon skill, each with a stated basis. **None of this is a community
tier list, and none of it is presented as one.**

- **`dpsProxy`** = `avgDamage / (attackDelaySec + rechargeDelaySec)`, computed purely
  from the item's own stats. It is a **comparison proxy**: it ignores initiative caps,
  crit rate, add-damage, damage modifiers, buffs and special attacks. It ranks these
  weapons against each other; it is **not in-game DPS**.
- **`ipWeightedReq`** = Σ (each `ToWield` skill/special requirement × MP's cost factor
  for that skill, from `skillcaps.json`). A relative burden number, not an IP total.
  MP's cheap skills are Pistol 2.4, Bow 2.5, 2hEdged 2.5, 1hBlunt 2.6; the expensive
  ones are 1hEdged, 2hBlunt and MeleeEnergy at 4.0 — which is real, load-bearing
  information for an MP choosing a weapon.
- **Top damage** — highest `dpsProxy`, reported with its gates so an unreachable pick
  is obvious.
- **Best value** — best `dpsProxy / ipWeightedReq` **among models still reaching 60% of
  that skill's top dpsProxy**. The 60% floor is a stated threshold; without it the
  ratio just elects the weakest cheapest weapon.
- **No expansion needed** — best `dpsProxy` with no expansion gate at all.

## 6. Re-running this, and doing the other 13 professions

```powershell
# 1. extract (parameterised by profession id)
cd E:\Funcom\AOBuddy10\tools\mp-weapon-extractor
dotnet run -c Release -- --prof 12 --out "$env:TEMP\metaphysicist_weapons_raw.json"

# 2. generate
.\gen-weapons-endgame.ps1 -ProfessionId 12 -Slug metaphysicist `
    -ProfessionName Metaphysicist `
    -WeaponSkills Bow,Pistol,1hBlunt,2hEdged,MeleeEnergy,1hEdged,2hBlunt

# analysis only, no write:
.\gen-weapons-endgame.ps1 -AnalyzeOnly
```

`-WeaponSkills` is operator-supplied on purpose. The client data does **not** encode
"profession X uses weapon skill Y" — every profession can technically equip almost
anything — so inventing that table would break the ground rules. The per-skill cost
factors are emitted in the output to make the choice evidence-based for the next class.

The extractor also gained a **probe mode** for investigating items, which is how the
Modified Xan chain was confirmed locally:

```powershell
dotnet run -c Release -- --probe-only --probe-name "of the Xan" --probe-out out.txt
dotnet run -c Release -- --probe-only --probe-ids 280726,302942 --probe-out out.txt
dotnet run -c Release -- --probe-only --probe-desc "higher performance" --probe-out out.txt
```

Renderer support for the new sections is in `tools/aodb/app.py`
(`renderXanWalkthrough`, `renderBestBySkill`, `acqCell`, and an `esc()` HTML-escape
helper — the acquisition text legitimately contains angle brackets like
`<base weapon QL 299/300>`, which the browser was swallowing as tags).
**Restart the aodb server after pulling this**, since app.py changed.
