## Deviations from the template classes

- 343 CASTABLE NANOS - the largest kit of any class profiled so far (Engineer 288, Metaphysicist 286, Doctor 240, Soldier 177, Shade 79). 199 gate via Profession(60) and 144 via VisualProfession(368), a 42% VisualProfession share that sits between the Engineer's 37% and the Doctor's 83%; both paths had to be used or a third of the kit would be missing (playbook section 3).
- THE BUREAUCRAT SUMMONS BOTS WITH SpawnItem, NOT SummonPet - the Engineer pattern, not the MP pattern. All 65 bot nanos use SpawnItem[<4-letter code>,<level>,0]: nine families (BUWO Worker, BUHE Helper, BUAT Attendant, BUAS Assistant, BUAI Aide, BUSC Secretary, BUAD Administrator, BUMI Minion, BUBO Bodyguard) x seven grades (Basic, Limited, Faithful, Advanced, Supervisor-Grade, Executive-Grade, Director-Grade) = 63, plus Corporate Guardian (235386, BRBD) and CEO Guardian (273300, BRBY). The extractor was therefore run with --spawn-category "Pets - Bots" instead of the MP's "Summon Weapon / Shield (Creation)".
- MOST OF THE CRAT KIT IS A WRAPPER NANO. The Speeches, the AoE calms, the AoE roots/snares and the Corporate Leadership line do not carry their own effect: they AreaCastNano or TeamCastNano a SECOND nano that holds it. Before this pass those 55 nanos summarised as 'AreaCastNano[157518,8]' and said nothing. tools/mp-nano-extractor was extended (additively) to resolve ONE level, so each row now reads 'AreaCastNano[157518,8] => <name> [strain 238 DemotivationalSpeeches] {Modify CriticalIncrease -6}'. No other finished class needed this because no other class's kit is built this way.
- SIX NEW CATEGORIES exist that no finished class produced: Pets - Bots (65), Area Casts (AoE) (27), Root / Snare Breakers (21), Speeches - Enemy (Demotivational) (13), Speeches - Team (Motivational) (12) and Fear (9). Each rule is keyed to the nano's own NanoStrain line name or its own function id, never to a profession, and each fires only on what the old code would have dumped into 'Misc / Utility' - which is why Misc / Utility is down to 4 rows here.
- STACKING IS THE WHOLE STORY FOR THIS CLASS. All 13 Demotivational Speeches share NanoStrain 238, so only one can ever be on a target. The 12 Motivational Speeches split across THREE effect strains (234 MotivationalSpeechEffect, 182 CriticalIncreaseBuff, 237 MotivationalSpeechNanoResistBuff), so three of them CAN run together. The calms are strain 147, the roots 146, the snares 145. A reader who ignores the strain column will double-cast and overwrite.
- THE CRAT'S CALMS ARE INITIATIVE DEBUFFS IN THE DATA. Strain-147 'Mezz' nanos such as Sleep (30093) and Empowered Demotivate (224135) carry only 'Modify MeleeInit/RangedInit/PhysicalInit/NanoCInit -N' - no Mezz() function at all. Only 'Last Minute Negotiations' (267535) and its junior (267538), on strain 893, call the actual Mezz function. That is recorded as read; it is not a normalisation.
- 'Uncontrollable Body Tremors' (99577) IS NOT A BUREAUCRAT NANO. The playbook mentions it by id; checked here directly, its ToUse requires VisualProfession == 10, i.e. Doctor. The Bureaucrat's own initiative debuffs are the strain-186 'Malaise of ...' line (236506 / 236508 / 236514 / 275824).
- Hit[27,...] is a HEALTH hit and Hit[214,...] is a CURRENT-NANO drain (Stat.cs 0x1B and 0xD6). The Demotivational Speech line uses the second form, so several 'debuffs' here are nano drains. No earlier class file had to draw that distinction.

## Unverified / caveats

- RestrictAction (function 53068) is the root effect. Its ARGUMENT encoding has no enum anywhere in OmniCell.Enums, so it is printed raw as RestrictAction[4]. In this data it only ever appears with the argument 4 and only on NanoStrain 146 (Root) nanos - that correlation is the evidence, not a decoded constant. Do not read '4' as a named action.
- 17 Root-line nanos (55980-55993, 43368, 224115, 224117) carry ONLY RestrictAction; the client data holds no duration for them, so no duration is stated.
- The 'Psychic < N' ceiling on the Charm and Fear nanos is a cap on the TARGET, not on the caster. Evidence, from the client data only: on all 9 Fear nanos it appears in the SAME requirement list as 'NPCFamily != 0 / 94 / 95 / 96 / 97 / 98' (e.g. Crush Bravery 121140: Psychic < 229 next to six NPCFamily tests), and a player caster has no NPCFamily - so that whole group must be evaluated against the target. Caveat kept: the per-requirement Target field exists in the client structures but tools/mp-nano-extractor flattens it away, so this is inference from co-location, not a read of the Target field. See bureaucrat-pets.json for the full 37-nano table.
- 'Specialization op22 <bits>' and 'Pets op66 <n>' appear in castReqs verbatim. Operators 22 (BitAnd) and 66 are printed as op-codes because no enum in the local source names operator 66.
- minLevel is the nano's own ToUse Level requirement. A nano with no Level requirement shows minLevel 0; that means 'ungated by level', not 'usable at level 1' - the nano-skill requirements still gate it.
- Nanos are listed as CASTABLE, not as OWNED. Whether the crystal is obtainable is bureaucrat-nano-sources.json's job.
